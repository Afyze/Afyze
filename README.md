## 🚀 Featured project

### [RoadFix](https://github.com/lbrty-7/RoadFix)
An iPhone app for reporting road problems in the city (potholes, broken streetlights, damaged sidewalks). Residents snap a photo and pin it on a map, and city staff track each report from *Reported* to *Resolved*. Built with **Swift**, **SwiftUI** and **Firebase**.
